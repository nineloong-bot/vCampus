vCampus Shop 最终 Demo 使用说明
===============================

运行要求
--------
1. Windows 10 或 Windows 11。
2. 已安装 Java 21 或更高版本，并可在命令提示符中运行 java -version。
3. 完整解压本压缩包后再启动，不要在压缩包预览窗口中运行 BAT。

启动步骤
--------
1. 双击“启动服务端.bat”，保持服务端窗口开启。
2. 看到服务端启动成功后，双击“启动客户端.bat”。
3. 在登录页使用下列固定账号之一，统一密码：123456。

固定账号
--------
DEMO_BUYER        学生买家，可浏览、加购、结算、模拟支付和申请开店
DEMO_OTHER_BUYER  另一学生买家，用于订单隔离和购买新店主商品
DEMO_TEACHER      教师申请人，初始申请为已驳回，可编辑后重新提交
DEMO_ADMIN        管理员，可审核申请、管理店铺和维护商品/SKU，不可购买
密码：123456

固定目录
--------
共 5 家营业店铺、100 件在售商品：文具 10、图书 30、生活用品 45、药品 5、其他 10。
商品封面不新增数据库结构；每类提供 4 个内置封面（共 20 个），由客户端离线绘制符号占位。

建议演示顺序
------------
1. 买家：搜索筛选、商品详情、购物车、结算、模拟支付、查看已支付订单。
2. 教师：查看驳回原因，编辑申请并重新提交。
3. 管理员：审核申请；停业/恢复店铺；修改商品与 SKU 价格、库存。
4. 获批店主：重新登录后进入卖家工作台，新增含多个 SKU 的商品并上架。
5. 权限：店主不能购买自己的商品；管理员不能购买；停业店铺不可写且商品不对买家展示。

默认连接
--------
服务器地址：127.0.0.1
端口：8888

常见问题
--------
1. Address already in use：关闭此前占用 8888 端口的 Demo 服务端后重试。
2. 未找到 Java 或版本过低：安装 Java 21 并正确配置 PATH。
3. 客户端无法连接：确认先启动服务端，且服务端窗口仍在运行。
4. 每次启动服务端都会恢复固定 Demo 数据。
5. 运行日志会自动写入本目录下的 logs 文件夹。

目录说明
--------
lib       客户端与服务端可运行程序
config    日志配置
database  Demo 数据库、建表脚本和种子数据
logs      首次运行后自动创建的日志目录
