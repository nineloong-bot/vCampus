vCampus Shop Demo 使用说明
===========================

运行要求
--------
1. Windows 10 或 Windows 11。
2. 已安装 Java 21 或更高版本，并且可在命令提示符中运行 java -version。
3. 完整解压本压缩包后再启动，不要只在压缩包预览窗口内打开 BAT。

启动步骤
--------
1. 双击“启动服务端.bat”，保持服务端窗口开启。
2. 看到服务端启动成功后，双击“启动客户端.bat”。
3. 使用以下固定买家账号登录：
   登录标识：DEMO_BUYER
   密码：DemoPassword7

默认连接
--------
服务器地址：127.0.0.1
端口：19090

常见问题
--------
1. 提示 Address already in use：已有程序占用 19090 端口。关闭之前启动的 Demo 服务端后重试。
2. 提示未找到 Java 或版本过低：安装 Java 21，并正确配置 PATH。
3. 客户端无法连接：确认服务端窗口仍在运行，并先启动服务端、后启动客户端。
4. 运行日志会自动写入本目录下的 logs 文件夹。

目录说明
--------
lib       可运行程序
config    日志配置
database  Demo 数据库、建表脚本和种子数据
logs      首次运行后自动创建的日志目录
