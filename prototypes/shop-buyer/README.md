# 校园商城交互原型

用于确认买家、店主、管理员及虚拟余额的页面交互。正式客户端仍为Swing，网页原型不承担正式服务端功能。

在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8765/ 。

包含商品列表/搜索、购物车、开店申请、订单、虚拟钱包、商品编辑与Excel导入、举报、管理员列表及整改预览。管理员入口为 `#admin-shops`，店主商品入口为 `#seller-products`。

数据保存在页面内存中，刷新或重置后清空。图片使用预置资源编号，资质和举报采用文字资料；审核为模拟审核。Excel由本地解析，正式版向服务端提交结构化数据而非文件。

余额系统由商城开发负责人实现，账户模块仅接查询显示；原型中的余额适配接口不能视为已发布的Java协议。
