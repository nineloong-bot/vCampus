# vCampus 统一版本人工测试指南

## 启动位置

只使用隔离工作树：`E:\summer-school\vCampus\.worktrees\shop-auth-demo`。

在 `vcampus-distribution\scripts` 先启动 `start-server-with-data.bat`，确认端口为 `8888`；保持窗口不关闭，再启动 `start-client.bat`。客户端登录后应在同一个主窗口看到“学籍档案、课程中心、图书借阅、校园商城、账户设置”。

## 账号

所有账号初始密码均为 `admin123`。`ADMIN` 首次登录必须修改密码，例如改成 `Admin12345`，随后用新密码重新登录。

- `ADMIN`：综合管理员。
- `TEACHER01`：教师。
- `213230001`：普通学生和商城买家。
- `SHOPOWNER`：已通过开店申请的店主。
- `SHOPDRAFT`：保存了开店申请草稿。
- `SHOPPENDING`：已有待审核开店申请。

## 冒烟顺序

1. 管理员：检查账户管理、学籍管理、课程管理、图书馆书目/副本/借阅管理，以及商城申请审核均可进入。
2. 学生 `213230001`：查看本人学籍；课程中检查正常教学班、满员班和同时间冲突；图书馆查看在借与逾期记录。
3. 同一学生进入商城：购物车应有黑色与红色中性笔，默认均不勾选；分别测试删除单项、只勾选部分商品结算；订单中检查待支付和已支付记录。
4. 店主 `SHOPOWNER`：商品管理应分“上架商品”和“下架商品”两列；草稿位于下架列且不能直接上架。中性笔应可编辑黑色、红色两个商品种类。
5. `SHOPDRAFT`：打开开店申请弹窗，确认草稿回填、保存草稿、关闭时保存询问。
6. `SHOPPENDING` 与管理员配合：管理员刷新未处理/已处理列表；单击行后可在主界面通过或驳回，双击打开只读详情弹窗并可审核。
7. 教师 `TEACHER01`：验证教师课程页；确认不能进入管理员专属操作。

## 数据重置

关闭服务端后运行 `reset-data.bat`，输入 `y`。该脚本只删除 `vcampus-distribution\data\vCampus.accdb`；下次启动服务端会恢复上述账号和场景数据。
