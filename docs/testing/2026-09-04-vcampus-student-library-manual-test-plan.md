# vCampus 学籍与图书馆合并版人工测试方案

## 1. 测试目标

验证 `sTeven44` 当前集成版本中的最新学籍、图书馆、服务端启动脚本和商城审批刷新修改，并对用户管理、课程模块执行关键冒烟回归。

## 2. 测试范围与优先级

| 优先级 | 范围 | 通过标准 |
|---|---|---|
| P0 | 服务端 BAT、登录、学籍核心流程、图书借还、商城审批刷新 | 无阻断、无数据串号、页面状态正确刷新 |
| P1 | 学籍校验/隐私/PDF、图书副本/策略/状态约束 | 错误输入被明确拒绝，合法操作即时同步 |
| P2 | 用户管理、课程、界面一致性观察 | 关键页面可进入，原有主流程无明显回归 |

## 5. 启动与基础冒烟

### START-01 服务端双击启动

账号：无。

步骤：

1. 在资源管理器打开 `vcampus-distribution\scripts`。
2. 双击 `start-server-with-data.bat`，不要从已有命令行窗口启动。
3. 观察窗口是否保留，并等待服务端监听端口 `8888`。
4. 双击 `start-client.bat`，登录任一账号。

预期：

- [ ] BAT 窗口不会瞬间消失。
- [ ] 成功时显示启动提示并保持运行。
- [ ] 客户端能够连接并登录。
- [ ] 登录后能看到学籍、课程、图书馆、商城和账户入口。

### START-02 启动失败提示

仅在发布包副本中执行，不要改动当前工作树。

步骤：

1. 复制 `vcampus-distribution` 到临时测试目录。
2. 临时将副本中的 `config\server-with-data.properties` 改名。
3. 双击副本中的 `scripts\start-server-with-data.bat`。

预期：

- [ ] 窗口保留并提示缺少配置文件。
- [ ] 按键后窗口关闭，未启动残留服务端。
