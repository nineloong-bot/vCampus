# 《vCampus 虚拟校园系统软件设计说明书》构建说明

本目录是设计说明书的可维护源，最终交付物是仓库根目录下的
**`软件设计说明书-vCampus.docx`**。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `章节/` | 说明书的正文源文件，按章号命名（`01-引言.md` … `13-其他.md`）。**改文档内容改这里。** |
| `图/` | 说明书引用的 10 张框图 / 流程图 / E-R 图（PNG） |
| `工具/` | 构建脚本：`draw_diagrams.py` 生成插图，`build_doc.py` 组装 Word 文档 |
| `原始素材/` | 各模块设计事实的调研笔记，供核对细节使用，不进入正式文档 |

## 如何重新生成文档

```powershell
# 1) 需要时重新生成插图（依赖 matplotlib，使用系统微软雅黑字体）
python "docs\设计说明书素材\工具\draw_diagrams.py"

# 2) 组装 Word 文档（依赖 python-docx、Pillow）
python "docs\设计说明书素材\工具\build_doc.py"
```

生成结果覆盖 `软件设计说明书-vCampus.docx`。脚本以课程下发的
`软件设计说明书DEMO(20250825).docx` 作为样式模板，继承其页面设置、标题样式与 `Table Grid` 表格样式。

## Markdown 源支持的语法子集

`build_doc.py` 只实现说明书需要的子集，避免额外依赖：

- `#` / `##` / `###` 三级标题（对应 Word 的 Heading 1/2/3，进入目录）
- `####` 四级标题（渲染为加粗段落，不进目录）
- 标准管道表格 `| a | b |`，第二行为 `| --- |` 分隔行
- 围栏代码块 ```` ```java ````
- 列表 `- ` 与 `1. `
- 行内 `**加粗**` 与 `` `等宽` ``
- 插图：`![图 4-1 标题](图/fig-4-1-登录流程.png)`，图片按内容宽度自适应并自动居中、附图题

## 目录与页码

文档中的目录是真正的 Word `TOC` 域，并且已在 `settings.xml` 中设置
`<w:updateFields w:val="true"/>`。用 Word 打开时会自动更新并显示页码；
如未自动更新，在目录上按 `F9` 或右键选择"更新域"即可。

## 表格排版规则

表格由 `build_doc.py` 中的 `allocate_widths()` 统一排版，规则如下：

1. **固定布局**：所有表格设为 `tblLayout=fixed`，列宽由程序计算后写入，不交给 Word 自动分配，
   避免各列被平均切开。
2. **列宽分配**：先为每列留出"容纳其最长不可断行片段"的宽度（保证
   `fk_tblStudentProfileApplication_student`、`edu.seu.vcampus.client.course.ui`
   这类长标识符不被压碎），再把剩余宽度按各列内容总量分配；之后再做一次均衡修正，
   把宽度从行数明显更少的列挪给最差单元格偏高的列。
3. **断行点**：渲染前用 `soft_breaks()` 在标识符的 `_ . / -` 与驼峰分界处插入零宽空格，
   同时把段落设为 `<w:wordWrap w:val="1"/>`（不允许在单词中间换行），
   于是换行发生在语义边界上，而不是把名字逐字符劈开。
4. **其他**：表头在跨页时自动重复；单元格左右内边距收窄到 0.15cm；
   表头居中、纯编号列居中、正文左对齐顶对齐；页边距左右 2.4cm、版心 16.2cm。
5. **内容约定**：新增表格时保持"序号 | 名称 | 类型 | 约束 | 说明"这类列序，
   说明文字放在最后一列；避免在单元格里堆砌超长的整句约束描述，
   否则该行会被撑得很高。
