# 全模块测试数据包 Implementation Plan

**Goal:** 生成可直接启动的全模块批量测试包，保留现有数据库和业务代码。
**Architecture:** 使用当前发行 JAR 和数据库结构，在独立目录创建 Access 测试库；确定性生成关联数据，并进行数据库一致性与实际服务验证。
**Tech Stack:** Python 标准库生成 SQL、Java 21/UCanAccess 执行及验证、现有 vCampus 发行程序。
**Spec:** 用户要求覆盖学生、教师、课程、图书馆和商城；沿用建议的 1,000 名学生规模。

## 约定

- 1,000 学生、50 教师、独立管理员；测试密码 Test12345，账号清单明确标注首次改密场景。
- 120 门课、240 教学班及关联选课；500 种图书、馆藏及借阅；30 店铺、商品、购物车、订单、支付及库存记录。
- 测试包独立使用 18888 端口；所有资料均为合成测试数据。
- 程序脚本按功能拆分，单文件不超过 200 行，中文注释。
- 不覆盖整合项目数据库、不提交或推送现有工作区修改。
