## 演示顺序

1. 使用 `213260101` 浏览商品，选择不同规格，部分勾选购物车后提交待付款订单。
2. 使用 `213260001` 查看青禾文具铺、商品草稿和店主订单；使用 `TESTADMIN` 审核店铺、资质和举报。
3. 使用 `213260104` 查看退款审核中的订单和钱包退款流水；使用 `213260105` 查看已完成订单及店主收入结算。
4. 使用 `TESTADMIN` 处理晚风杂货铺的暂停营业和恢复申请，观察商品限制不会被一并解除。
5. 打开两个 Excel 样例，先预览正常导入，再用混合校验样例展示原始行号和错误原因。

## 重置

关闭客户端和服务端后，将只读基准库复制为工作库，再按 `vcampus-distribution/config/server-with-data.properties` 启动服务端。不要在唯一基准库上反复支付、退款或修改库存。待付款订单应在正式演示前通过真实下单流程重新生成，以保持库存预占和有效期一致。
