# 商城正式接入与验收

本次交付将已确认的商城流程接入统一登录后的 Swing 客户端、Socket 服务端和 Access 数据库。网页原型仍用于设计对照；正式入口是客户端导航中的“商城”。

## 模块范围

| 模块 | 已接入能力 |
| --- | --- |
| 商品与购物车 | 商品草稿、稳定 SKU、默认规格、预置图片、上架校验、软删除、搜索排序分页、Ctrl/Shift 多选、购物车规格数量与部分结算、Excel 本地解析和服务端预览/重验 |
| 订单与库存 | 多店订单、30 分钟库存预占、余额付款、失效商品懒校验、取消、退款审核、发货、确认收货、超时释放、库存流水 |
| 店铺与监督 | 文字开店资料、模拟审核、专项资质及过期限制、举报、关联商品警告、停业与复业申请、商品紧急下架及整改复核、审计历史 |
| 独立余额 | 100/200/500 快捷充值、单次上限1000、精确分值、扣款、退款、收货后商家收入结算、不可变流水、账户模块查询接口 |

管理员仅有店铺管理、商品管理两个列表入口。买家右上角为购物车、我的、首页；购物车用绿点表示非空，选择框与结算按钮位于右侧，分页和结算栏固定在滚动区外。商品图片与客户端一起发布，数据库存图片编号。店主订单只展示公开昵称，未设置时显示“校园用户”。

## 启动与升级

1. 使用 JDK 21，先退出旧客户端并停止旧服务端。
2. 启动 `vcampus-distribution/scripts/start-server-with-data.bat`。
3. 服务端启动后，启动 `vcampus-distribution/scripts/start-client.bat`，登录并进入商城。

客户端和服务端必须使用本次同一批 JAR。生产路由使用 `SHOP2_*` 和 `WALLET_*`；旧 `SHOP_*` 模拟支付路由不注册到正式服务器。旧专项 Demo 启动脚本继续用于旧演示，不用于验证本次正式流程。

服务端启动按顺序安装 schema 051–054 的增量表，随后启动订单超时及资质维护任务。本次先在发布数据库副本重复升级验证，原发布数据库不被替换。发布包中的 SQL 与源码保持一致。

旧模拟订单保留历史查询，显示“历史订单”；没有真实余额托管记录的旧订单不进行新版扣款或收入结算。旧待付款库存仍由旧预占超时任务释放。新创建订单完整运行新版生命周期。

## 并发与边界

- 商品可购状态、库存、订单、余额扣款和回执在服务端事务内重新检查。
- 支付、退款和收货具有持久化幂等回执；网络结果未知时，页面原操作重试使用同一请求编号。
- 商城和充值使用各自隔离的资源锁，数据库事务仍共享；避免定时维护与学籍批量建号因资源锁槽碰撞而形成反向等待。
- 余额使用整数分，库存和账户更新带条件检查；验证了两名买家竞争最后一件商品。
- 部分失效只解除对应库存并重算应付金额；全部失效自动取消，已失效行不因重新上架复活。
- 商品删除保留 SKU、历史订单和流水；存在未完成订单时拒绝删除。
- 资质到期只限制依赖该资质的商品；普通类目转换解除无关资质限制，紧急下架限制仍独立生效。
- Excel 文件只在客户端读取，发送结构化记录；最多1000行。预览不写业务数据，确认时再次校验，以商品分组为单位导入合格草稿。

当前部署按单个服务端进程访问一个 Access 文件设计，不能将本次并发验证解释为多主机同时直接写同一个数据库文件的支持。

## 可复现验证

```powershell
mvn test
mvn '-Dtest=Commerce*Test,ServerMain*Test,ShopUiTest,WalletDemoDatasetTest' '-Dsurefire.failIfNoSpecifiedTests=false' '-Dcommerce.release.validate=true' '-Dwallet.demo.generate=true' test
mvn package
mvn javadoc:aggregate
```

- `CommerceAcceptanceTest` 使用真实 Socket 会话和 Access 串联开店、审核、商品、充值、购物车、支付、发货、收货、举报与管理员处置。
- `CommerceReleaseMigrationTest` 将当前发布库复制到 `vcampus-server/target/commerce-release-validation`，两次初始化后核对表及原用户/商品/订单数量，校验源文件 SHA-256 未变化；结果写入 `manifest.properties`。
- `WalletDemoDatasetTest` 生成1000笔操作、2000条平衡分录、250条订单资金记录，位于 `vcampus-server/target/wallet-demo/dataset-*`。这是专项验证库，不是完整可登录校园运行库，不应替换发布库。
- UI 截图由真实数据页面渲染生成，位于 `vcampus-client/target/commerce-ui-review`。

账户模块对接说明见 [wallet-api.md](wallet-api.md)，订单服务契约见 [order-api.md](order-api.md)。
