# vCampus 使用说明

## 运行环境

- Java 21 或更高版本。
- 服务端默认监听 `127.0.0.1:8888`，数据库位于 `data/vCampus.accdb`。
- 如需调整端口，服务端与客户端的 `config/*.properties` 必须保持一致。

## 启动

macOS / Linux：

1. 运行 `scripts/start-server.sh`。
2. 服务端启动后运行 `scripts/start-client.sh`。

Windows：依次运行 `scripts/start-server.bat` 和 `scripts/start-client.bat`。

## 调试提示

- 启动脚本固定使用 `lib/vCampusServer.jar` 和 `lib/vCampusClient.jar`；同目录下带版本号的瘦 JAR 不用于脚本启动。
- 服务端从 `config/server.properties` 读取 `database.path=data/vCampus.accdb`。脚本会先切换到发布目录根目录，因此可以从任意当前目录调用。
- 服务端日志位于 `logs/server.log`；数据库、业务和安全日志分别位于 `logs/database.log`、`logs/business.log`、`logs/security.log`。
- 调试前先确认 8888 端口没有被其他服务占用；配置端口时同时修改客户端和服务端属性文件。

## 学籍管理流程

- 学生可编辑个人基本信息；学籍信息中只有“就读方式”允许学生修改，且必须从下拉列表选择。
- 输入框悬停时会显示格式提示。日期、身份证件、联系方式、身高体重等字段会进行合理性校验；入学日期时必须已年满 18 周岁，身高范围为 100–280 CM。
- 编辑内容先保存为草稿，不会直接修改正式学籍。学生点击“提交审核”后，管理员审核通过才写入正式信息。
- 待审期间按钮显示为“撤回申请”。撤回后保留上一版修改内容，学生可继续编辑并重新提交。
- “导出基本信息 PDF”导出当前正式、规格化学籍信息。
- 管理员可查看学生完整信息，并在学籍标题旁编辑管理员可维护的学籍字段。

## 组织管理与手动新增

组织管理页始终显示“新增学院、新增专业、新增班级、新增学生”四个入口：

- 未选择节点时只有“新增学院”可用。
- 选择学院后只有“新增专业”可用。
- 选择专业后只有“新增班级”可用。
- 选择班级后只有“新增学生”可用。

手动新增学生与自动录取使用不同命令，不改变原有录取流程。必填项包含一卡通号、学号、姓名、性别、学生类型、证件类型、证件号、出生日期、入学日期和所选班级。
