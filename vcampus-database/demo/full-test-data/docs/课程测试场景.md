# 选课与培养方案场景

- 当前仅有 `2026-2027学年秋季学期`，状态为 ACTIVE，正式选课阶段为 OPEN。
- 104 门课程均有 2 个教学班，共 208 个教学班和 208 条完整排课。
- 所有教学班初始已选人数为 0，`tblEnrollment` 与 `tblEnrollmentAdjustment` 均为空。
- 15 套培养方案覆盖 5 个专业、2024～2026 三个年级和 8 个学期；学分包含 1、1.5、2、2.5、3、3.5、4、5、12 等档位。
- 2024 级已有前 4 学期必修成绩，2025 级已有前 2 学期必修成绩，2026 级没有历史成绩。

人工测试时，学生完成首次改密后进入选课中心，任选课程的 A/B 两个教学班之一。重复选同一课程、容量、时间冲突和退选由现有业务规则检查。初始状态不预埋任何选课结果，便于观察每一步写入。
