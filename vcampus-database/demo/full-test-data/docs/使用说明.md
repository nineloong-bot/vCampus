# vCampus 初始数据使用说明

所有初始账号密码均为 `123456`。学生首次登录后必须修改密码；管理员和教师可直接进入系统。

| 账号 | 身份 |
| --- | --- |
| `ADMIN` | 超级管理员 |
| `STUDENT` | 学籍管理员 |
| `COURSE` | 选课管理员 |
| `LIBRARY` | 图书管理员 |
| `SHOP` | 商城管理员 |
| `USER` | 用户管理员 |
| `CSADMIN` | 计算机科学与工程学院管理员 |
| `MATHADMIN` | 数学学院管理员 |
| `T001`～`T024` | 教师 |
| 三段一卡通号 | 学生 |

完整学生、姓名和用途见 [账号清单](../tools/账号清单.md)。

## 推荐人工检查

1. 使用 `ADMIN` 检查模块管理员、学院、专业、班级和账号数量。
2. 使用 `213240001`、`213240002` 检查逾期借阅、罚款和钱包；精确书名与金额见账号清单。
3. 使用 `MATHADMIN` 检查 5 条数学学院转出申请，使用 `CSADMIN` 检查目标学院。
4. 使用任一学生完成首次改密后测试选课；初始没有任何选课或选退历史。
5. 使用 `SHOP` 检查开店申请、资质、举报、整改和恢复记录。

重置时必须停止服务，并从已验证的发行数据库副本恢复；不要对正在运行的数据库执行生成器。
